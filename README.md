# ✨ Iztro Project: Unveiling the Cosmos ✨

This project is a React-based application that visualizes and interacts with astrological charts, specifically focusing on the Izpalace system. It provides a detailed view of horoscope data, including palaces, stars, mutagens, and time scopes. The application allows users to explore and analyze astrological information in an interactive and responsive manner. It leverages the `iztro` library for astrological calculations and data, and React for building a dynamic user interface.

## 🚀 Key Features

*   **Interactive Astrological Chart:** Displays a detailed Izpalace chart with interactive elements.
*   **Dynamic Data Visualization:** Visualizes horoscope data, including palaces, stars, and mutagens.
*   **Time Scope Exploration:** Allows users to explore horoscope data across different time scopes (decadal, yearly, monthly, daily, hourly).
*   **Heavenly Stem Highlighting:** Highlights heavenly stems based on user interaction.
*   **Responsive Design:** Adapts to different screen sizes for optimal viewing experience.
*   **Date and Time Adjustment:** Provides controls for adjusting the horoscope date and time.
*   **Lunar Date Conversion:** Calculates and displays the lunar date based on the selected solar date.
*   **Central Information Hub:** The `IzpalaceCenter` component displays key astrological information in a clear and organized manner.

## 📦 Getting Started

Follow these steps to get the project up and running on your local machine.

### Prerequisites

*   Node.js (version >= 16)
*   npm or yarn or pnpm

### Installation

1.  Clone the repository:

    ```bash
    git clone <repository_url>
    cd <project_directory>
    ```

2.  Install the dependencies:

    ```bash
    npm install # or yarn install or pnpm install
    ```

### Running Locally

1.  Start the development server:

    ```bash
    npm run dev # or yarn dev or pnpm dev
    ```

2.  Open your browser and navigate to the address provided by Vite (usually `http://localhost:5173/`).
